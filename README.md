# 雾湖 · Mistlake

A theme Profile for CatOS niri + DMS. It is a complete catdot Profile derived from `catos-niri-dms` (`catos-niri-mistlake`), and the palette is pushed out to the whole system from a single DMS theme file.

## Design

Night over a misty lake: the surfaces are not pure black but the blue-green of lake water at night, in five depth steps; the accents carry over the lake cyan, add a moss green from the forest, and keep a single warm lantern amber that appears only on things that are genuinely urgent.

| Role | Dark · Night | Light · Dawn | Used for |
|---|---|---|---|
| primary | `#5ec8d8` lake cyan | `#00707e` | focus ring, selection, primary actions |
| secondary | `#9cc9a8` moss | `#3f6b4f` | secondary highlights, success |
| tertiary / warning | `#e7b874` lantern | `#8a5a12` | urgent and unread items, the only warm colour |
| background | `#0d1417` | `#f1f5f4` | base |
| surfaceContainer | `#0a1013` → `#27373e` | `#ffffff` → `#d6e1e0` | five depth steps |

Contrast has been checked against WCAG: body text is 13.9:1 in dark mode and 15.2:1 in light mode, and every accent is above 3:1 against surface.

Shape and motion: 14px window radius, 10px gaps, long low shadows; springs critically damped with no bounce, and windows open with a 220ms ease-out. Terminal font is Maple Mono NF.

Shell: a floating island bar 10px off the screen edge, 82% translucent with a 1px mist outline and no per-widget pills; widgets reduced to launcher, workspaces, focused window | music, clock | tray, clipboard, notifications, control center. Popups and the launcher are blurred with a thin outline. UI font is Inter Variable (Chinese falls back to Noto Sans CJK). Urgent states use lantern amber, leaving red for errors.

## Shortcuts

|---|---|

## Layout

```text
profile.toml        catdot Profile manifest (packages + manage)
tree/               content tree, installed to /usr/share/catos-niri-mistlake/, mirrors $HOME
  .config/DankMaterialShell/themes/mistlake/theme.json   palette (managed)
  .config/DankMaterialShell/themes/mistlake/shell.json   bar, widget, popup and font preset (managed, merged in by mistlake-apply)
  .config/niri/mistlake/{look,motion,binds}.kdl         shape, motion and shortcuts (managed)
  .config/niri/mistlake/accents.kdl                     urgent color, loaded after dms/ (managed)
  .config/niri/catos/*.kdl                               unchanged from upstream, for easy syncing
libexec/mistlake-apply   merges shell.json into DMS settings.json (backing it up first), restarts and regenerates colors
bin/mistlake-wallpaper   wallpaper picker that searches subfolders
tools/validate           stages the Profile, then runs catdot validate + niri validate
PKGBUILD                 local package
```

niri load order: `catos/` (upstream baseline) → `mistlake/` (this theme) → `dms/` (generated by DMS) → `mistlake/accents.kdl` → `custom/catos-niri-mistlake/` (your own changes).

Why DMS settings take an extra step: DMS keeps its state in its own `settings.json`, which belongs to no Profile, and its IPC cannot set arrays or objects (the bar is an array). So catdot manages `shell.json`, and `mistlake-apply` merges only the keys listed there into `settings.json` (backing it up to `~/.local/state/catos-niri-mistlake/settings-backups/` first); every other setting is left as it is.

## Install and switch

```sh
cd ~/Projects/catos-niri-mistlake
tools/validate
makepkg -si                          # install the Profile into /usr/share (needs sudo)
catdot plan catos-niri-mistlake      # preview what changes; nothing is modified
catdot select catos-niri-mistlake    # switch; installs Maple Mono and backs up overwritten files
/usr/lib/catos-niri-mistlake/mistlake-apply
```

Backups of overwritten files are in `~/.local/state/catdot/backups/`.

## Iterating

1. Edit files under `tree/`, then run `tools/validate`.
2. `git commit`, bump `pkgver` or `pkgrel` in `PKGBUILD`, then `makepkg -si`.
3. `catdot update catos-niri-mistlake` (only managed paths are refreshed; seed files are not touched).
4. If the Profile's `packages` changed: `catdot select catos-niri-mistlake` installs the missing packages.
5. `/usr/lib/catos-niri-mistlake/mistlake-apply`.

## Switching back

```sh
catdot select catos-niri-dms
dms ipc call settings set currentThemeName cyan
dms ipc call settings set currentThemeCategory generic
dms restart
```
